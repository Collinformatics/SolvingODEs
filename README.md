# About:

Computational Ordinary Differential Equations.

The code is based on the book "Solving Ordinary Differential
Equations in Python" by Dr. Joakim Sundnes.

    https://link.springer.com/book/10.1007/978-3-031-46768-4

Install modules:

    python -m pip install -r requirements.txt
